# Intel-oneAPI
This repository contains programs for GPU programming using SYCL (DPC++).

## Access on your HBIntel300 IdeaCentre Tower
- Go the start menu and open: Intel oneAPI command prompt for Intel 64 for Visual Studio 2026
- Inside of this Intel oneAPI terminal, type: cd %USERPROFILE%
- mkdir oneAPI_projects
- cd oneAPI_projects

## Set-up
### Download the toolkit
- Go to Intel oneAPI Base Toolkit: https://www.intel.com/content/www/us/en/developer/tools/oneapi/base-toolkit-download.html
- Choose Windows → offline installer.

### Install Miscrosoft Visual Studio Community.
- During the installation, download "Desktop development with C++""
- Set-up the oneAPI exe
- If you want to connect to GitHub (optional), download Git for Windows at https://git-scm.com/install/windows

### Open the Intel oneAPI Terminal
- Go the start menu and open: Intel oneAPI command prompt for Intel 64 for Visual Studio 2026
- Inside of this Intel oneAPI terminal, type: cd %USERPROFILE%
- mkdir oneAPI_projects
- cd oneAPI_projects
- Clone your GitHub repository: git clone https://github.com/h-n-belzer/Intel-oneAPI.git
- Go into your cloned GitHub repository: cd Intel-oneAPI
- Open VS Code to develop code: code .
